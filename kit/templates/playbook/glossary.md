# Glossary

Use this page when you need the word this repository uses for a concept.

## Where it lives
<!-- slot: where · required -->
When the repository keeps a glossary, this form points at it, and `paths.glossary` in the config
names the same page. The glossary defines the words; the knowledge registers hold the rules. An entry says what a
term is, not how it is implemented. When several words exist for one concept, the canonical one is
defined and the others are listed under *Avoid*.
