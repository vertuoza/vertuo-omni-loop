Strict TypeScript across the kit, game and omni-app

PRD 725. About 460 files and 83 000 lines of plain JavaScript become strict TypeScript. Nothing a person sees changes: the same commands, the same output, the same bundle. What changes is what an agent learns while it edits.

An agent passes the wrong shape

A slice changes what readOutbox returns. Its caller in another folder still reads the old field.

Today 
// kit/lib/status/board.mjs
const items = readOutbox(dir);
for (const item of items) {
  line(item.severity);   // field renamed to risk
}

No error. If a test covers this line it fails later, with undefined three calls away. If none does, it ships.

After 
// kit/lib/status/board.ts
const items = readOutbox(dir);   // OutboxItem[]
for (const item of items) {
  line(item.severity);
}
board.ts:4:13 - error TS2339: Property 'severity'
does not exist on type 'OutboxItem'.

The compiler answers on the edit, before any test runs, and CI refuses the pull request.

Reading something from outside

Config YAML, a PRD's front matter, a gh response, the environment.

Today 
const cfg = YAML.parse(read('.omni-loop/config.yml'));
const limit = cfg.limits.stallDays;   // trusted as is

A missing or mistyped field flows on as undefined. Only 29 files import Zod.

After 
const cfg = ConfigSchema.parse(YAML.parse(read(path)));
// type Config = z.infer<typeof ConfigSchema>
ZodError: limits.stallDays: expected number, received string

Every outside read passes a Zod 4 schema first, and the error names the field. The type comes from the schema, so they never drift.

What stays the same

  • The bundle other repositories run: .omni-loop/bin/omni.mjs, built by esbuild from the .ts sources.
  • Every omni command, its flags and its output; every skill and the plugin.
  • The arcade's screens, the GitHub App's checks, the game's scores. No behaviour changes, and the existing suite proves it.
  • The database: no migration. Its types are generated from the migrations that exist.
  • No build step for scripts: Node 22.18 or later runs .ts itself.
