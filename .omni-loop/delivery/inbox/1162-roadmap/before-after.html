What stays the same

  • A PRD is built as today: its issue, spec, plan, waves, outbox gate, feature PR. A roadmap only orders PRDs.
  • The loop never merges into any default branch, never answers the outbox, never adds the outbox label.
  • /omni:drive without --roadmap drives your PRDs as PRD 1139 made it.
  • Every target PR and every review stays in its own repository.
