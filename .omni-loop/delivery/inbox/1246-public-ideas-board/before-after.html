Members set the lanes, and votes sort the ideas within each lane. Pressing ▲ while signed out starts a GitHub sign-in that asks for no org access and comes back here. Pressing it again takes the vote back. A private board answers "no public board here". Example counts and PRD number.

On the page, a member also edits ideas, drags them between lanes, archives them, sets a PRD number, and copies each card's line: /omni:brainstorm 'Better UX on the approval gate: …'. The board goes public or private in Settings › Repositories.

What stays the same

  • Every other workspace page stays members-only. A board is off until a member turns it on.
  • Brainstorms, PRDs and the loop are unchanged. An idea becomes a PRD only when someone runs /omni:brainstorm.
  • Members sign in as they do today. Only a voter's sign-in is new.
