---
prd: 728
title: A PRD delivered in any workspace repository earns its people points
---
A PRD delivered through Omni Loop now earns points in any repository the workspace tracks in Settings → Repositories, including PRDs built across several repositories. Points and XP start again from 0 on the day this ships: nothing earned before counts any more, and the games you already unlocked stay unlocked. Two repositories that both have a PRD 88 now show as two planets in the arcade.
