PRD 2543: before and after

galaxy

Functional

Today
  1. The playbook's pages are read from the workspace's plan repository, the same one the game, the dossiers and the points use.
  2. No page lets anyone choose it. A workspace with no plan repository reads "No settings repository yet" and is told to name a plan repository, with nothing to click.
  3. The guide gives SQL to set it, and setting it that way also moves the workspace's planets and points.
After
  1. Settings › Playbook says, at the top, which repository the playbook is read from.
  2. While none is chosen, the plan repository is used by default, and the owner keeps it as the settings repository in one click.
  3. The owner can pick any repository the workspace lists, change it, or clear the choice to go back to the default.
  4. Members see which repository is read, with no control to change it.
  5. The game, the dossiers and the points keep reading the plan repository: choosing a settings repository moves nothing else.

Pixel perfect

screens: settings-playbook · app-shell (unchanged). The Settings tabs and the page cards below are unchanged; the dashed outline marks what the PRD adds. The mockups use the Omni theme of Ask's reading tokens.
