A stale write is not a fast-forward, so git refuses it. The App only wakes and reads; the repair rules come from the default branch, which only a person merges.

The architecture

  • Laptop closed: the App's ledger wakes the mission; the laptop only reads the ref.
  • Bounded repair: limits live on main; a retro's proposal is a pull request a person reads.
  • Migration: today's drive writes the same ref first, before the App wakes any mission.
