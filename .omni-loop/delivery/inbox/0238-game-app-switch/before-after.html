PRD 238 · before / after

One tap between the game and the app

Omni Loop has a fun side, the arcade at /, and a professional side: the pages where people read Claude's questions and the knowledge map, and soon the PRDs. Today nothing joins them, and you cross by typing an address. After this PRD, the Game Boy has a GAME ▮▯ APP switch, SELECT MODE has an APP MODE row, and every page of the app has Game mode at the top right. Each crossing asks first.

The two crossings

Each side has one home. Leaving the game lands on /app. Leaving the app lands on SELECT MODE, past the boot and the title. Both ask before they go.

The Game Boy, held upright

The wordmark row gets a small slide switch at its right end, in the body's colours. Nothing else on the body moves. SELECT and START stay the pad's buttons. The switch looks like hardware, because it leaves the game.

Switch to game mode?

The arcade opens on its menu.

StaySwitch

Switch has the focus and goes to /#menu, in the same tab. Stay, Esc or a click outside closes it, and the page is as it was. The same button ends the header of /app, every /ask/* page and /knowledge.

What stays the same

The padThe D-pad, A, B, SELECT, START and the grille work as they do today. The switch is not a pad action and appears in no key hint.
The scenesThe 24 scenes and their grids are unchanged. The confirm is an overlay over them.
The address /It still starts at the boot. Only /#menu, a new deep link, starts at SELECT MODE.
Each page's sign-in/ask and /knowledge keep their own sign-in, callbacks and states.
The artifactThe single-file arcade has no server and no /app, so it shows neither the switch nor the row.
DataNo table, no API route, no kit command. Nothing is stored, and a revert undoes it all.
