Omni Loop kit: terraform any repository with the delivery loop

One source for the brainstorm → inbox → yolo → outbox → yolo-fix → shipped loop. Everything specific to a repository lives in a removable .omni-loop/ folder, and the skills ship once as a Claude Code plugin. This page is for checking the design and the Phase 1 plan before any code is written.

The loop

The folder is the status. No front matter carries status, priority or value.

PlanWaves of slices, a collision check, a draft feature PR with Closes #prd.inbox/0042-topic/plan.md
YoloClaims each slice first, builds test-first, records every decision it took./omni-yolo 42

Review focus

Inputs the spec doesn't mention but a person will hit. Each one has a test in the task named.

  1. A typo in config, such as outboxgo:Every command stops and names the file and the key. It never silently uses the default. Task 1.
  2. PRD numbers of any widthomni prd 42 finds 0042-topic/; PRD 12345 finds 12345-topic/. Task 2.
  3. Two ADRs with the same numberResolution fails and names both files. Task 4.
  4. Shipping a PRD with no outbox, or with links in settled.mdThe first ships; the second leaves settled.md byte-identical. Task 14.
  5. The bundle with no node_modules, outside git, or with no configWorks in the first case. In the others it prints one line and exits 2, with no stack trace. Task 15.
