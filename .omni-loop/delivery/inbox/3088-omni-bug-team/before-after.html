PRD 3088: before and after

omni-app

Functional

Today

When a mission meets an Omni Loop bug, the App files the issue (or a +1) and the PRD stops with Waits on Omni Loop bug #N. Nobody takes the issue, and nothing tells the mission when it is fixed.

After

A standing mission on the Omni Loop repository takes the reported bugs, most-reported first, and fixes each one with /omni:bug-fix, one pull request a person merges. Once the release holds the fix, every mission that waited on it is told, and its PRD resumes by itself once its repository runs that kit.

galaxy

Functional

Today

The Operation room of a mission that met the bug reads Stopped: Waits on Omni Loop bug #N, for good, until a person presses Resume on the whole mission.

After

The team's room lists each bug it holds (fixing, waiting for a merge, asked, fixed in v0.0.N). A waiting mission's room reads Omni Loop bug #N is fixed in v0.0.N, then Fixed in v0.0.N: update the kit to resume or Resumed; a bug closed as not planned reads take this PRD by hand.

supabase

Functional

Today

A mission's scope is a list of PRDs, and the bug reports are a count per fingerprint with no state.

After

A mission has a kind (prds or omni-bugs); each bug report has a state, its attempts, its fix pull request and the version that fixed it.

kit

Functional

Today

/omni:mission writes a mission over PRDs or roadmaps only.

After

/omni:mission --omni-bugs writes the bug team's brief in one line, on the Omni Loop repository only.

Flow

Deploy order

  1. The migration 20270127100000_omni_bug_team.sql (additive: a column with a default, nullable columns, wider checks).
  2. The Omni App (reads the new columns and webhooks; inert until an omni-bugs mission runs).
  3. The galaxy app (the room's rows).
  4. The kit release (/omni:mission --omni-bugs).
  5. Subscribe the App to the issues and release events of the Omni Loop repository (until then the sweep moves the states).

Behaviour

Today

outcome() leaves a PRD stopped on an Omni Loop bug until a mission-wide Resume; conclude() delivers a mission once its PRDs merged.

After

An omni-bugs mission never concludes and picks bugs (bug-team.ts); a PRD stopped on a bug that is fixed resumes when its pinned kit is at fixed_in or later, spending no repair (BR-PRODUCT-139 gains this way back).
