PRD 1646 · Cut Vercel build costs

Each Vercel project (galaxy, omni-app) builds only when a change can reach what it deploys. Production on main stays automatic; previews stay for ready pull requests into main.

1,700 → ~300
production builds a month
every push → 1 per burst
preview builds, ready PRs into main only
65.8k → ≤ 10k
Build CPU Minutes a month (target −85%)
