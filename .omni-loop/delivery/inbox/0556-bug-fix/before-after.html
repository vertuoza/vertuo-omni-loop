/omni:bug-fix 'saving twice duplicates the row'
  1. Opens an issue labelled omni:bug, or reads the one given.
  2. Classifies it: a flaky check is tooling, and it stops.
  3. Triage comment: domain, risk, regression with evidence. Labels omni:risk-high, omni:regression.
  4. Needs a product decision, a stored shape or a new route? Stops with the /omni:brainstorm line.
  5. Words first, then the reproduction, run: it must fail. Green before the fix: stops.
  6. The smallest fix, test-first; the reproduction is never edited.
  7. The guard, then the mutation check when commands.mutation is set.
  8. Writes bugs/0612-duplicate-row/bug.md; omni bug 612 prints ok.
  9. One PR into the default branch, Closes #612. A person merges.

What stays the same

  • The loop for features: /omni:brainstorm, phase-0, /omni:yolo, waves and the outbox.
  • /omni:visual-fix, the first fast lane, and its omni visual proof.
  • The bug-fixing playbook form: a repository's own steps still add to the skill's.
