PRD #99 · vertuo-omni-loop · 25 September 2026

OmniMan signs the loop's work, and omni credits counts it

Today Claude is credited on everything the loop builds, and the loop itself is not. After this PRD, OmniMan (the omni-loop app's bot, omni-loop-invader[bot]) is a co-author of every commit a skill makes, signs every pull request and issue a skill opens, and has a track record anyone can print.

A slice commit, as GitHub shows it, and the lines at the end of its message. Drawn, not captured: GitHub's own wording around the avatars may differ.

The second line is what omni sign trailer prints. When the feature pull request is squash-merged, GitHub carries both co-authors into the commit on main.

The end of a pull request or issue the loop opened

Pull requests and issues have no co-author on GitHub, so OmniMan signs the description, just above the session's own lines. The hidden marker is what omni credits recognises.

Any one is enough. The signature then only says how he shows: signed, before signing (history, before the repository's first signed item) or missed (a skill forgot to sign it). A pull request closed without merging does not count.

What stays the same

  • Claude's trailer and "Generated with Claude Code" line stay exactly as they are. OmniMan is added beside them.
  • A commit a person makes by hand is not signed, and comments are not signed.
  • omni ship checks nothing new: a feature branch may carry a person's fix.
  • Pull requests and issues are still opened by the person, via Claude. The app opens nothing new.
  • The game, the galaxy arcade and the Hall of Heroes do not change. An OmniMan card in the arcade is a later PRD.
  • signature: null in a repository's config switches all of it off; the skills then run as today.
