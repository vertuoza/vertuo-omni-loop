## The question, in plain words

The runner's built-in help text does not yet mention the new option for how many days job logs are kept. Should it be added there too?

## The decision, in plain words

The option works and the kit's guide describes it, but the built-in help was left as it was, because the slice was only allowed to change the runner's own files and the guide.

## The intro, for fun

The runner learned to tidy its room, but its help page has not heard the news yet.

## The punchline, for fun

One line of help is all that stands between a person and the option they are looking for.

## The options, in plain words

A. A. Leave the built-in help as it is in this slice; add the option to it in a follow-up change (built).
B. B. Add the option to the built-in help in this PRD, as a small slice of its own before the feature is marked ready.
C. C. Never list it in the built-in help: the guide is enough.

## What I had to decide

Whether the runner's built-in help names the log-keeping option in this PRD, or in a follow-up change.

## What I did meanwhile

A person reading only the built-in help does not learn the option exists; the kit guide and the usage line printed on a bad flag both name it.

## What it costs to change later

One line of help text and its detail sentence, in a file outside this slice's territory; no behaviour changes.
