PRD 1066 · Import boundaries

Nothing on screen changes. What changes is what the tests refuse when an agent wires a layer the wrong way.

Today

The rules are comments

// The App imports nothing from the arcade.
// The game never imports the kit but for its ID brands.
// A lower layer never imports a higher one.

What compiles, ships

apps/galaxy/src/arcade/sure.ts
  import … from 'vertuo-omni-plan/kit/test/…'   // test fixtures in source
game/cli/workspace.ts
  import … from '../../kit/lib/env/read.ts'     // against its own comment
kit/lib/statusline/board-cache.ts
  new URL('../../bin/omni.ts', …)               // the library reaching up
apps/galaxy/src/jev/secret-box.ts
  import 'node:crypto'                          // no server-only marker

✓ fallow --circular-deps: 0 cycles

What stays the same

  • Behaviour and output: the breaches are moved or marked, never rewritten.
  • Which kit/lib modules apps may use: all of kit/lib stays open; kit/bin and kit/test close.
  • Scripts stay free to import anything: they are repository tools.
