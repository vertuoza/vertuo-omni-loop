2. The fix

Today by hand

$ git stash   # maybe
$ git switch main
$ git pull
$ omni version
omni v0.0.414
latest v0.0.423, run: omni update
$ omni update
$ /plugin update omni@omni-loop  # and the HUD?

Five commands a product manager has to remember, every morning.

After one command

$ omni sync --fix
  ✓ switched to main (feat/old-idea had nothing unpushed)
  ✓ fast-forwarded main: 14 commits
  ✓ updated the plugins — a new session loads them
  ✓ omni update: opened #2011 (kit v0.0.423)
  ✓ refreshed the page's copy
🟢 In sync

Only the safe steps: a clean tree, nothing unpushed, fast-forward only. Never merges, rebases, resets or pushes; anything it leaves is printed with why.

Once all four hold it is recorded, and this checkout is never 🔵 again. Someone already set up never sees it.

A finding shows the lower of its own colour and its check's level. The headline is the heaviest check's first finding of the status's colour.
