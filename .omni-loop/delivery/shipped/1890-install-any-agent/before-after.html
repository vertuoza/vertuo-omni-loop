Install for any coding agent

PRD #1890 · Architectural · PRD 3 of the agent-agnostic series, after #1831 and #1858. A repository lists its agents; the install writes every omni skill where Codex, Cursor and Gemini CLI read them, keeps them in sync, and help shows each agent's form. Claude keeps its plugin.

Functional

Today

$ omni init

  .omni-loop/bin/omni.mjs
  .claude/settings.json   # statusLine, HUD
  claude plugin install omni@omni-loop

$ omni init --agent codex --agent claude
