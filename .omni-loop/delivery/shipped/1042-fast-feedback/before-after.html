PRD 1042 · A feedback loop in seconds

Nothing on screen changes. What changes is how long an agent waits to know whether its change is right.

Today

An agent checks a three-file change

$ pnpm typecheck        6 s
$ pnpm lint            43 s   1,709 files, up to ~5.6 GB
$ pnpm test            62 s   674 files
≈ 2 minutes, after every change
$ git commit           fallow audits the main checkout,
                       not this worktree

A wave

at most 4 agents at once on 32 GB

CI on a push (after settle's 180 s)

CheckTime

test174 s

After

The same change

$ pnpm check:changed
  typecheck  (whole, tsgo)          ~2 s
  lint       3 changed files        ~3 s
  tests      related to them        ~3–10 s
  fallow     against origin/main    ~2 s
≈ 20 s, and the worktree's own code is audited

Before marking a sub-PR ready

$ pnpm test && pnpm lint   the full gate, once, unchanged

CI on a push (settle unchanged)

What stays the same
