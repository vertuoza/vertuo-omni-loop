Today: what installs it

  • .claude/settings.json › PreToolUse runs .claude/hooks/fallow-gate.sh on a Claude Bash call that looks like a commit or push.
  • It fails open on a missing jq, a missing fallow, or an audit error.
  • The verification form says "a commit hook runs …", but git has none.

After: what installs it

  • pnpm install → prepare → git config core.hooksPath .githooks, for every worktree of the checkout.
  • .githooks/pre-commit and .githooks/pre-push, tracked, plain shell, no hook manager.
  • The Claude-only hook and its settings entry are deleted; the briefing hook stays.
  • .github/workflows/quick.yml: settle 30 s, then pnpm check:changed --base origin/<base>.
  • --no-verify stays the emergency hatch; the PR says why.
