PRD 1180 · before / after

Every answered question earns points

Today an answer to the agent's question moves only the "Questions answered" count. After this PRD, each answered question tied to a numbered PRD pays its answerer 2 points and 2 XP, the same from the Omni page or the Claude terminal.

One QUESTION_ANSWERED ledger event per answer, written on the next hourly poll, dated when it was answered. Past answers since the game began are backfilled.

2. An answer given in the terminal when the page round did not open

Today
pre hook: open round → server down
terminal: person picks "Both"
post hook: no round file → returns, nothing recorded

The same silence when the round came back closed, or when one question was left empty.

After
pre hook: open round → server down
terminal: person picks "Both"
post hook: opens and answers in one call → recorded, via terminal

Closed rounds and partly answered rounds are recorded too. A post that still fails prints one line instead of nothing.

3. A settled outbox item that names its approver badly

Today
- Approved by: @pierrederval
ledger contributor "@pierrederval" → matches no player, kept forever
After
- Approved by: pierrederval
ledger contributor "pierrederval" → credited

A name with @, a dot or upper case is skipped with a warning, so the event is written correctly once the name is fixed.

What stays the same

  • Answers that belong to no PRD (a spike, ad-hoc work) earn nothing and still count as Questions answered.
  • Threat, decay and terraform ignore answers.
  • Events already in the ledger are never rewritten, including past credits under a wrong name.
  • Every other way of earning points pays exactly what it paid before.
