PRD #7 — the loop drives itself

Before: each Omni Loop PRD was built by hand, with decisions kept in private notes. After: a person types three commands, and the loop runs every step, writes every decision as an outbox item, and ships before merge.

Before (PRD #3)

  1. A human writes the spec and plan, and dispatches subagents task by task.
  2. Slices are committed straight onto one branch. There are no sub-PRs and no claims.
  3. About 20 rulings go into a private ledger and are raised as outbox items only at the end.
  4. The feature PR merges unshipped. A cleanup PR (#6) then settles and runs omni ship 3.
  5. The skills that do all this live in another repository and hard-code it (vertuo-*).

After (with /omni:*)

  1. /omni:brainstorm: the PRD issue, spec, plan and this page, then a phase-0 PR a person merges.
  2. /omni:yolo 7: the board comes from GitHub; each slice is claimed as a draft sub-PR, built test-first, and merged into the feature branch.
  3. Each decision taken without asking becomes an item through omni item new, ranked by the kit.
  4. You answer on the feature PR: 1: ok or 2: B because ….
  5. /omni:yolo-fix 7: it settles the answers, reworks what drifted, runs omni ship, and marks the PR ready. A person merges.

The cut-over: waves 1–5 of this PRD are built with the loop run by hand. Wave 6 (yolo-fix, brainstorm) is built by /omni:yolo 7 itself.
