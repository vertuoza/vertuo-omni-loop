PRD 347 · before / after

Know which kit you run, and get the latest in one command

Today the kit has no version: a merge to main changes what the next install takes, and nothing says which one a repository runs. Updating means init --force, which rewrites config.yml, and the Claude plugin never updates at all. After, every merge is a numbered release, omni version says where you are, and omni update opens one pull request that brings the repository to the latest, and updates the plugin too.

A merge to main

vertuo-workflow-domain
$ omni update
v0.0.9 → v0.0.15
  bin      updated
  config   kept, valid under v0.0.15
  forms    1 created (.omni-loop/knowledge/playbook/security.md)
  labels   ok
  plugin   updated to v0.0.15, run /reload-plugins
PR: https://github.com/vertuoza/vertuo-workflow-domain/pull/88

The work happens in a worktree on chore/omni-update-v0.0.15, so your checkout is never touched. A person merges the pull request. omni update --to v0.0.12 goes back to a given version. The first time, a repository installed before versions runs npx github:vertuoza/vertuo-omni-loop update.
