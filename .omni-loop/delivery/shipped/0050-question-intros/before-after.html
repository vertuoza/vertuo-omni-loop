The rules, and the fallback

A line

  • One sentence, at most 120 characters, in plain words: no code name, path or id.
  • About the question or its situation. Never about a person or a team, and never mocking whoever answers.
  • An agent's line may name anything in the repository's world, the game included.
  • Every open or adopted question gets both lines, whatever its rank or layout.

An item without lines

  • The kit's pool fills in. The pick is keyed on the item's id, so rewriting the comment never changes it.
  • No pool line repeats within one comment, and a new question never changes an older one's lines.
  • The pool never names the game: PRD 3 keeps the kit free of it, and a test lists the words.
  • This covers items raised before this PRD, and every older adopted entry, since the ledger is append-only.

What stays the same: the heading, the question, the options and the reply lines; the Answered section; the PRD issue's comment and the Slack note; whether an item is required to have its lines (it is not).
