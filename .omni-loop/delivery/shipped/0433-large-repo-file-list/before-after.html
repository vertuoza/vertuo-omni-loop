PRD 433 · kit · no screen changes

The kit keeps working when a repository's file list is over 1 MB

Only the terminal output changes. In a large repository, omni check all and omni ship crash today because the kit caps git ls-files at Node's default 1 MB. After this change they run normally.

omni check all, in a repository with a 1.1 MB file list

today 
$ node .omni-loop/bin/omni.mjs check all
check inbox — ok
check outbox — ok
Error: spawnSync git ENOBUFS
    at trackedFiles (check-report.mjs:11)
    at checkKnowledge (check.mjs:73)
  code: 'ENOBUFS'
exit 1

The crash also stops /omni:invade and /omni:brainstorm, which both run check all.

after 
$ node .omni-loop/bin/omni.mjs check all
check inbox — ok
check outbox — ok
check knowledge — ok (14 entries)
…
exit 0

check knowledge lists only its own folder, so its output grows with the knowledge folder, not with the repository.

omni ship, at the end of /omni:yolo

today 
$ node .omni-loop/bin/omni.mjs ship 12
Error: spawnSync git ENOBUFS
    at trackedFiles (check-report.mjs:11)
    at applyShip (ship.mjs:75)
after 
$ node .omni-loop/bin/omni.mjs ship 12
moved inbox/0012-… → shipped/0012-…
rewrote links in 3 files
