PRD 522 · mega-invade

A plan repository that knows its target repositories. Part 1 of the multi-repository mode: vertuo-automation-plan learns which repositories hold the code, what each one does, and where each one's knowledge lives. Planning across them (mega-brainstorm) and building across them (ultra-yolo) come next.

Where the repositories stand

today
  • The loop's config holds one repo.slug. A PRD, its plan and its pull requests all live in that one repository.
  • Which repository does what is only prose, in docs/git-repositories/README.md.
  • A repository with no knowledge base gives a planner nothing to read.
after
  • The plan repository's config lists its targets, a one-word role each, and where each one's knowledge lives.
  • The guide stays the prose; the config points at it and never copies it.
  • A target with no knowledge base can get a draft imported into the plan repository, stamped with the commit it was read at.

Setting it up

today · /omni:invade
  • Explores the repository it runs in, and only that one.
  • Writes that repository's own knowledge base, in one docs-only pull request.
after · /omni:mega-invade in the plan repository
  • Survey: the guide's repositories, plus the config's targets, each read for loop, version and filled forms.
  • One map, one answer: target or not, its role, and for one with no knowledge base, import one or not.
  • Import: a read-only shallow clone, invade's four facets, drafts under .omni-loop/knowledge/repos/<name>/. Nothing runs in the clone.
  • One docs-only pull request in the plan repository: the config as its own commit, the readiness table, and one next step per gap. Nothing is written in any target.
  • --sync redraws only what changed in stale imported copies, and proposes own when a target installs its own knowledge base.

What stays the same

  • A repository with no plan section: its config, its commands and its skills behave exactly as today.
  • /omni:invade, /omni:brainstorm and /omni:yolo are unchanged. This PRD adds no repository column to plans and opens no pull request in a target.
  • The plan repository's own knowledge never reads an imported copy: an id in a copy never binds it.
  • The Omni app, the GitHub App and the game are untouched.
