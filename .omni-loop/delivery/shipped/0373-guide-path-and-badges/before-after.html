Today

A shortcut for the omni command

The kit's command is the file .omni-loop/bin/omni.mjs, run with Node. These pages write it omni. To type it that way too, add a shortcut in the terminal you work in:

alias omni='node .omni-loop/bin/omni.mjs'

Optional, only at the repository's root, gone in the next terminal. Skip it and the next step fails with command not found: omni.

After

Put omni on your PATH

Once per laptop. This writes a small omni command that runs the kit of whichever repository you are in, from any folder of it:

Terminalmkdir -p ~/.local/bin
cat > ~/.local/bin/omni <<'SH'
#!/bin/sh
root=$(git rev-parse --show-toplevel 2>/dev/null)
kit="$root/.omni-loop/bin/omni.mjs"
if [ -z "$root" ] || [ ! -f "$kit" ]; then
  echo "omni: no Omni Loop kit here (.omni-loop/bin/omni.mjs). cd into a repository that has it." >&2
  exit 2
fi
exec node "$kit" "$@"
SH
chmod +x ~/.local/bin/omni
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
exec zsh

On bash, write ~/.bashrc and exec bash instead. Check it, from any folder of your repository:

TerminalCoding agentomni help

A block with both badges also runs in Claude Code: type it there with ! in front, like ! omni help.
