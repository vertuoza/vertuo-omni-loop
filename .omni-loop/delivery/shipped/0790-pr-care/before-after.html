What changes, what stays

Changes

  • A new skill, /omni:pr-care <n>, runs locally and watches the feature PR only.
  • A new review playbook form (fix · push-back · ask) that each repository can edit.
  • A health chip in the PRD header and a new PR care tab, both read live from GitHub.
  • /omni:yolo's hand-off suggests /omni:pr-care once the PR is ready.

Stays the same

  • No new tables, webhooks or cloud runners. Verdicts live on GitHub as reply markers.
  • /omni:pr's CI and conflict steps, and its 3-attempt limit.
  • Sub-PRs, phase-0, retro and fix PRs are not watched.
  • A person still merges. The reviewer keeps the last word.
