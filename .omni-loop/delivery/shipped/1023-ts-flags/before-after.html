PRD 1023 · The last strict compiler flags

Nothing on screen changes. What changes is what the compiler refuses.

Today

Missing and undefined look the same

type Options = { title?: string };
const o: Options = { title: undefined };
✓ compiles     'title' in o is true, though nothing was given

A parameter nobody reads

function render(rows, now) { return rows.map(line); }
✓ compiles     now is never read

A method shadowed by accident

class Store extends Base { read() { … } }
✓ compiles     Base.read is silently replaced

The flags

strict · noUncheckedIndexedAccess
6 more checks off: 231 errors waiting

After

The type says which it is

type Options = { title?: string | undefined };   // what the code does
or, for a body sent out:
{ ...(title === undefined ? {} : { title }) }    // absent, not undefined

An unused parameter is an error

✗ 'now' is declared but its value is never read

Overriding is said out loud

class Store extends Base { override read() { … } }

+ noFallthroughCasesInSwitch · noUnusedLocals · noUnusedParameters

What stays the same
