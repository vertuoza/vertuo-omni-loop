The contract

GET /api/loop/changes?repo&base|head|label&statethe changes (pull requests) with head, base, state, labels, bodygh pr list
GET /api/loop/changes/<n>?repoone change, its last commit, files and review (checks, mergeable, threads)gh pr view, gh pr diff, gh api graphql
GET /api/loop/comments?repo&on=<n>a change's or an issue's commentsgh api …/comments reads
GET /api/loop/issues…issues by label, or one issue with its commentsgh issue list, gh issue view
