PRD #1233 · what a person gets from a PRD's acceptance criteria, today and after

Today

1

/omni:prove 1017 films each criterion once on the PR's preview.

2

Each criterion gets a verdict: ✓ ✗ or unfilmable.

3

The clips go to the PRD's Proof tab. The scripts are thrown away.

4

The next PRD that breaks the same screen is caught by a person, if by anyone.

After (beta, off by default)

1

/omni:validate-e2e 1017 reads the spec's criteria (never the code's diff) and writes one test per criterion a screen can show.

2

A first run on the preview records each goal step; a second run with --strict-cache must pass.

3

omni e2e status and omni e2e heals say, without a model, which recordings are missing and which steps changed.

4

A sub-PR into the feature branch carries the tests and their recordings. A person reads it, merges it, and the tests reach main with the PRD.
