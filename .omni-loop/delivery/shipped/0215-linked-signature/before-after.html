The settings

Today the hero’s name is typed twice and there is nowhere to put a link. After, the footer is a template: {name} and {home} are filled in from the keys above it. Set any key in a repository’s .omni-loop/config.yml to change that repository, or change the kit’s default to change them all.

The kit may carry the arcade’s address

The kit never names the game: a guard fails on the word “galaxy” in any kit file that is not a test (ADR-0002). A new ADR adds one exception, the arcade’s address as the default link. Any other use of the word still fails.

What stays the same

Unchanged

  • The skills: they print whatever omni sign trailer and omni sign footer print.
  • The hidden marker, and signature: null switching signing off.
  • A repository that wrote its own footer with no {…} in it: it prints exactly as before.
  • The arcade, its hero sprite and the docs, which keep “OmniMan”.

Accepted

  • omni credits matches a commit by its exact co-author line, so commits signed “OmniMan” before the merge leave its co-authored commit count. Pull requests and PRD issues keep counting through their labels and the marker.
  • Bodies and commits already signed keep their old line.

Rollback: revert the feature pull request, or set signature in one repository’s config.
