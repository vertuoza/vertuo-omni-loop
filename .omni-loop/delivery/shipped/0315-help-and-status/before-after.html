PRD 315 · before / after

Ask the loop what it is, and where things stand

Today omni help and a bare omni status are usage errors: two lines on stderr, exit 2. After, omni help explains the loop and every command, and omni status shows the repository's PRDs by stage, a bar of delivered against in progress, and the PRDs you worked on. Both are typeable inside Claude too, as /omni:help and /omni:status. omni status <prd>, the outbox gate, does not change.

omni help <command> tells more about any of them.

Exit 0. omni --help and omni -h print the same. A bare omni keeps its usage line and exit 2, with one line added: omni help: what each command does.

omni help <name>: one command, or one skill

Any of the 26 commands or 13 skills, named as board, yolo or /omni:yolo. A name that is both (plan, ask, status, help) prints the command, then the skill.

PRD n's slices as the loop sees them, rebuilt from GitHub on every run: each
slice's state (merged, stuck, in flight, runnable, blocked) and the wave that
can run next. Needs gh logged in.

$ omni help /omni:yolo
/omni:yolo <n>                                               for you

Builds a whole PRD with nothing asked along the way: plans it if needed, runs
the waves until every slice is merged, then runs the outbox gate. Green, it
ships and marks the feature PR ready; red, the questions wait on the feature
PR. It never merges into main.

omni status: the inbox, the outbox, what shipped, and yours

Read from git only, as last fetched: the default branch for the inbox and shipped folders, the feature branches for the outbox and its open items, the phase-0 branches for the PRDs in review. Nothing is read from GitHub. --fetch fetches first.

omni help: the loop and every command

An example: the branches behind the outbox and in-review rows are made up, and the … stands for the rest of the list, which is printed in full. The bar counts shipped against shipped + inbox + outbox; in review is counted but stays out of it. With no user.email, or in a shallow clone, the "Yours" section is one line saying how to fix it, and the counts and the bar still show.
