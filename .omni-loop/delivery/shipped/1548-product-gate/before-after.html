PRD 1548 · concept #1269 · area product-gate · ◆ server

One gate, no plan PR

A PRD that spans several repositories lives on its product, on the server. Each target's feature PR gets one check that it was approved, the outbox gate is read on the product, questions are answered on the product's Questions tab, and no plan repository is needed. Example data: Mobile, with nimbus-api and nimbus-app.

Run from any checkout of a product repository that has the kit. Every target must be phase0: server; a target on pr is refused by name.

What stays the same A one-repository PRD, ◆ or ◇, keeps its issue, its folder and its outbox files. A PRD already in a plan repository finishes there. The code still lands on GitHub, one feature PR per target. Roadmaps, bug records and knowledge packs move later, in area product-records.
