Answer the outbox anywhere

When /omni:yolo ends red, the questions its agents left can be answered in the terminal, on the PRD's page in the Omni page, or on the pull request. Every door writes the same reply, under the person's own GitHub account, so /omni:yolo-fix and the ledger change in nothing. The examples are PRD 216's real outbox on pull request #219.

Three doors, one record

Today there is one door, the pull request. After, there are three, and they meet in one place: a reply on the feature pull request. The Omni page reads the pull request itself, as the omni-loop App (PRD 426's reader): the questions, the replies already given and the settled ones. The App does not change.

A dossier

  • Its repositories: the home repository, plus the repository of every question attached to it.
