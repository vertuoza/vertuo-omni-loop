3 · The question behind the PRD: .claude/ or .agents/?

Assumed

Claude has moved to .agents/, so this repository should move off .claude/.

Checked (code.claude.com, 2026-10-12)

  • Claude Code still reads settings, skills, hooks, commands and subagents from .claude/, and reads no .agents/ directory.
  • The shared standard is the file AGENTS.md (agents.md, Agentic AI Foundation). Claude Code reads it natively when there is no CLAUDE.md, and recommends CLAUDE.md = @AGENTS.md when both are needed.
  • Moving .claude/ would switch off the briefing hook, the plugins, the fallow gate and the statusline.

The voice objected at the design (persona:B-E DEv): "I'd only trust it if every command in it actually runs, and it says which ones are slow." Accepted: every command is run green before it is listed, with its time.
