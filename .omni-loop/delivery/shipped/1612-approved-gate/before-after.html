The omni/approved gate: one check on every PR, the attestation one click away

A PRD approved on its page leaves no trace where code is reviewed. After this PRD, every feature PR of a PRD born on the server, and every target PR "Part of" it, carries one check that reads the approval from the server and compares it with the PR's own files.

When it runs: webhooks, never a poll

pull_request opened · synchronize · reopened · edited · ready_for_review  → rerun on that PR
issues       labeled omni:approved   (a member approved on the PRD page)   → rerun on every open PR of the PRD
issues       unlabeled omni:approved (new: an approval voided removes the label) → rerun on every open PR of the PRD
read         GET /api/approvals/judge?repo=…&prd=918   signed by the App (STAGE_EVENT_SECRET)
