After · /docs/skills/dossier-push (new page, one per skill)

/omni:dossier-push

send a PRD's files to its dossier

What it does

Sends PRD n's spec, plan and before/after page to its dossier on the Omni page, adding a version only where a file changed. /omni:brainstorm runs it after each of its pushes, and /omni:plan after it pushes the plan; it never stops the skill that runs it.

When to use it

Use it when you edited a PRD's spec or plan by hand and want the Omni page to show the new version.

How to use it

/omni:dossier-push <n>

Example

/omni:dossier-push 580

→ the dossier's link, and the versions it added

Who runs it

Other skills run it: /omni:brainstorm, /omni:plan.

Related skills

/omni:brainstorm · /omni:plan
