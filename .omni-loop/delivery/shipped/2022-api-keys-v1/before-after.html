How a call is answered, after

The routes, after

RouteAnswersToday
GET /api/v1/prds?limit=&cursor=the workspace's PRDs, newest first: ref, title, repository, product, stage, linksno route for a program
GET /api/v1/bug-fixes?limit=&cursor=the workspace's bug fixes, newest first: number, title, repository, linksno route for a program
POST /api/v1/bug-fixes202 and the queued runner job /omni:bug-fix '…'only Send to terminal, by a person
GET /api/v1/jobs/{id}the job's status, runner and pull requestonly the Runners page
GET /api/v1/openapi.jsonthe OpenAPI 3.1 reference, with no key; /docs/api renders it, and docs/guide/api.md explains itno reference
