PRD 3035: before and after

kit

Functional

Today

In a repository that never turned design craft on, a PRD that changes a page (a new unit on a figures page, say) gets a before/after page whose Pixel perfect tab reads only "N/A — design craft is off here". The person approving the PRD sees no screen.

After

The same PRD's Pixel perfect tab shows the figures page today beside after. The agent copies today's page from the app's own code and styles, draws after with only the new unit, and says under the screen anything it had to guess.

A PRD that changes no screen still says "Pixel perfect: no screen changes". With design craft on, nothing changes.
