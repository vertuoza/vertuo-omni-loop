PRD 284 · before / after

Omni · Light · Dark: the homepage's palette on the app

The theme switch on /app, /ask/*, /knowledge, /prd and /releases reads Omni · Light · Dark instead of System · Light · Dark. Omni is HOME's void, navy and comic yellow, and the default. Light and Dark are today's themes, unchanged. Only colours change between the three: the layout, the faces, the sizes and the controls are the same.

A first visit to /ask

Nothing stored. Today the page follows the system and lands on the neutral Dark (or Light). After, it opens in Omni, with Omni pressed.

In Omni the signal is comic yellow with the void's text on it, as HOME's PRESS START: the selected option's edge, the pressed theme, Send and Game mode. The Recommended badge turns magenta, so it never reads as a selection.

After: three themes, one layout

The same page in each theme. Light and Dark are today's, token for token; only the switch's first button changed.
