PRD 1723 · before / after

Observability on Vercel at near-zero cost

The arcade (apps/galaxy) and the GitHub App (apps/omni-app) tell someone when they break, and why, using Vercel's own tools, one shared JSON logger, a health endpoint per app and an hourly GitHub Actions check. No new vendor.

Functional

1 · A log line

Today

Free-text strings, only when something goes wrong. No duration, nothing to filter on.

outbox check of acme/widgets for 42 is held: the GitHub budget is spent
After

One JSON line per webhook, Inngest run and cron run, written through kit/lib/log. Only allow-listed fields; credentials masked; no stack.

{"level":"info","event":"inngest","fn":"outbox-check",
 "outcome":"failed","ms":1840,"repo":"acme/widgets","prd":42,
 "runId":"01J…","error":{"name":"HttpError",
 "message":"401 for https://api.github.com/…?token=***"}}

2 · When a route starts failing

Today

Nothing fires. Someone notices the board is stale. Runtime logs may already be gone after a day.

After

Vercel's error anomaly alert emails the team when a route's 5xx count over five minutes spikes. Observability Plus stays on behind a spend limit and keeps 30 days of searchable logs.

3 · GET /api/health

Today 
GET https://…/api/health
404 Not Found
After 
GET https://…/api/health
200  Cache-Control: no-store
{"ok":true,"app":"galaxy","commit":"e64412c…",
 "checks":{"env":"ok","supabase":"ok"}}

503  when a check fails
{"ok":false,"app":"galaxy","commit":"e64412c…",
 "checks":{"env":"ok","supabase":"failed"}}

Never a value, an error's text or a person. Never calls GitHub, Inngest or OpenRouter.

4 · When an app is down

Today

No check. A dead deployment looks the same as a quiet one.

After

Found by its exact title, no label. The run exits 0: the issue is the alert.

5 · What it costs

Today
  • Vercel Pro, already paid.
  • Whether Observability Plus is on, and its cost, written nowhere.
After
  • Vercel Pro, already paid.
  • Observability Plus: $1.20 per million events, behind a spend limit; the real cost read on the Usage tab a month after shipping and written in docs/guide/observability.md.
  • GitHub Actions: about 720 minutes a month for the hourly check.
  • No Sentry, no Log Drains, no new vendor (ADR-0102).
What stays the same: galaxy's pages and route handlers keep their console.error strings; every request, Inngest retry and onFailure behaves exactly as today; nothing in the database changes. New server code logs through kit/lib/log (conventions form).
