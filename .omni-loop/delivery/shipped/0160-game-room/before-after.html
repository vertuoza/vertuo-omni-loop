Deliver, level up, unlock arcade games

Every point a player earns by delivering now also counts as XP, and XP never resets with the season. Levels open cabinets in a new game room. The first point opens the first one: Entropy Invaders, where your own hero fights the alien Entropy.

Your hero against the alien Entropy

The player's own hero, the OmniMan body in their fleet's colours, flies along the ground and fires plasma bolts up at the formation. The aliens are the galaxy's Entropy, one wound kind per row.

5 · How XP is counted

XP is every point you ever earned by delivering

Seasons still reset the Hall of Heroes. XP never resets. Every 15 minutes the game workflow recomputes each player's XP from the whole ledger, using the rules in one block of game/rulebook.mjs.

CHANGING THE RULES

Change a number in this block and merge it to main. At the next poll, within 15 minutes, pnpm game:xp recomputes every player's XP from the whole ledger. A game once unlocked stays unlocked, even if new rules lower a level. How to play gains a LEVELS page that reads the same block, so the rules shown never drift from the rules applied.

7 · What stays the same

Delivery scoring does not move

Season points and rankingsThe Hall of Heroes, the fleets wall and the weekly rankings read the same economy as today.
The ledgerAppend-only and unchanged. XP is read from it, never written to it.
The scoring rulesEvery points value in the rulebook stays as it is. XP only adds a block beside them.
Games never scoreA high score is a bragging right on its cabinet. It never earns points or XP.
