The guide

Today
  • “An Omni Loop invite. The app is invite-only while it is in beta.”
  • “The kit's repository is private… that account needs read access.”
  • Troubleshooting: “npm says repository not found” → ask for access, run gh auth setup-git.
  • “Sign in with the GitHub account your invite was sent to.”
After
  • You need a GitHub account, and the Omni App installed on your account or an org of yours.
  • No private-repository or invite text anywhere.
  • Troubleshooting: “refused (403): you are not a member of …”
  • Troubleshooting: “no workspace owns … yet” → install the App.

What stays the same

  • Vertuoza colleagues: same sign-in, same ask pages, same dossiers, through the vertuoza workspace.
  • The web pages: you see only your own workspaces' dossiers and questions, as today.
  • How workspaces are made (PRD 359): your account, your org, or the org you pick on GitHub's install screen.
  • No workspace is seeded with anything.
