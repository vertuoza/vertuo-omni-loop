Agent-agnostic basics

PRD #1739 · Bounded. Three CLI defaults stop assuming Claude Code: the context files, the session id and where a flow hook belongs. Nothing changes for a Claude Code session.

Functional

1 · Which file holds the agent instructions

Today

paths.context:  [CLAUDE.md]          # default
laws (claudeMdInvariants):
  reads CLAUDE.md                    # hardcoded
  • A repository with only AGENTS.md (Codex, Cursor, Copilot, Gemini CLI): no context file is read, and omni init never finds its invariants.

After

paths.context:  [AGENTS.md, CLAUDE.md]   # default
laws (claudeMdInvariants):
  first file of paths.context
  that holds "## Invariants"
  • AGENTS.md is read first, CLAUDE.md still read when present.
  • Config keys keep their names: a config that sets them reads as before.

2 · The session id a dossier is tagged with

Today

$ codex
› /omni:brainstorm …
$ omni dossier open 'An idea'
  CLAUDE_CODE_SESSION_ID → unset
  POST /api/dossiers {title, repo}   # no session
  • Under any agent but Claude Code, the draft is linked to no session.

After

$ omni dossier open 'An idea'
  1 OMNI_SESSION_ID          → unset
  2 CLAUDE_CODE_SESSION_ID   → unset
  3 .omni-loop/local/session.json → none
  → generate 6f1c…, store it
  POST /api/dossiers {title, repo, claudeSessionId: "6f1c…"}

$ omni dossier push 1739      # from a worktree
  3 .omni-loop/local/session.json → 6f1c…   # same id
  • Linked with nothing to type. A team can still set OMNI_SESSION_ID in a wrapper.
  • Claude Code: its variable wins at step 2, as today.

3 · Where a flow hook belongs

Today

$ omni check config
  flow.areas.kernel.hooks.do-work.test:
  .claude/hooks/tests.md sits under .claude/ —
  mark it { path: .claude/hooks/tests.md, alias: claude },
  or move it out of .claude/
  • Says what is wrong, names no place to move it to.

After

$ omni check config
  flow.areas.kernel.hooks.do-work.test:
  .claude/hooks/tests.md sits under .claude/, which only
  Claude Code reads — move it to .agents/hooks/, or mark it
  { path: .claude/hooks/tests.md, alias: claude }
  • Points to .agents/hooks/, the folder agents share. A hook there is a plain path.
  • alias: claude stays for what only Claude Code reads (pr.openWith: /create-pr).
