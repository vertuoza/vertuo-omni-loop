# Install

Glossary term: Install

What `omni init` and `omni update` write into a repository, and where.

Its files are the `install` area of `.omni-loop/config.yml` (`flow.areas.install`, `knowledge: install`): `omni kb laws --paths` lists this folder's entries under **Applies here** for any file there (PRD 2346). An entry moved here from `product/` keeps its id, marked by its `Kept id:` line.
