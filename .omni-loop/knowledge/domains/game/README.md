# Game

Glossary term: Game

The game: the ledger and its points, the arcade and its games, fleets, levels and high scores.

Its files are the `game` area of `.omni-loop/config.yml` (`flow.areas.game`, `knowledge: game`): `omni kb laws --paths` lists this folder's entries under **Applies here** for any file there (PRD 2346). An entry moved here from `product/` keeps its id, marked by its `Kept id:` line.
