# Approvals

Glossary term: Approval

Approvals: a PRD's request for a person's yes, its stream of news, its voiding when an approved file changes, and the wait the terminal shows.

Its files are the `approvals` area of `.omni-loop/config.yml` (`flow.areas.approvals`, `knowledge: approvals`): `omni kb laws --paths` lists this folder's entries under **Applies here** for any file there (PRD 2346). An entry moved here from `product/` keeps its id, marked by its `Kept id:` line.
