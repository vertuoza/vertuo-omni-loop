# Push

Glossary term: Phone alerts

Phone alerts: the push subscription of each device, and what a tap on a notification opens.

Its files are the `push` area of `.omni-loop/config.yml` (`flow.areas.push`, `knowledge: push`): `omni kb laws --paths` lists this folder's entries under **Applies here** for any file there (PRD 2346). An entry moved here from `product/` keeps its id, marked by its `Kept id:` line.
