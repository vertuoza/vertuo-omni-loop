# Ask

Glossary term: Ask mode

Ask mode: the questions an agent asks a person on the page, their rounds and answers, the hooks that carry them, and who may read them.

Its files are the `ask` area of `.omni-loop/config.yml` (`flow.areas.ask`, `knowledge: ask`): `omni kb laws --paths` lists this folder's entries under **Applies here** for any file there (PRD 2346). An entry moved here from `product/` keeps its id, marked by its `Kept id:` line.
