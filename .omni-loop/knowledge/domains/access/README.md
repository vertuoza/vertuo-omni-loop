# Access

Glossary term: Workspace access

Who and what may reach a workspace's work: the GitHub account a member links, the links an agent reads through, the tokens a terminal signs in with, and the secrets that never reach a browser.

Its files are the `access` area of `.omni-loop/config.yml` (`flow.areas.access`, `knowledge: access`): `omni kb laws --paths` lists this folder's entries under **Applies here** for any file there (PRD 2346). An entry moved here from `product/` keeps its id, marked by its `Kept id:` line.
